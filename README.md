Spotify-Inspired Music Player UI

A Spotify-inspired music player interface built using HTML and CSS. This project focuses on recreating the visual layout of a music streaming platform with a clean and responsive design.

Features

Sidebar navigation with Home and Search options.

Library section with playlist creation options.

Recently played and recommended music sections.

Music cards featuring albums and artists.

Bottom music player with playback controls.

Progress bar and volume controls.

Technologies Used

HTML5

CSS3

Bootstrap

Font Awesome

Google Fonts
